# Rust for Pythonistas: Starter Template

A small Rust application template for people who know Python and want to learn Rust.

## Prerequisites

Install these on your computer before using the project:

- **Git** — to clone and manage the repository.
- **Rust with rustup** — installs Rust and its package manager, Cargo.
- **Just** — runs the project's named commands.
- **Zed** (optional) — an editor. Other editors work too.

### Rust

Install Rust using [rustup](https://rustup.rs/). Then install the formatter and linter components:

```bash
rustup component add rustfmt clippy
